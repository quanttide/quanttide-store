# 量潮门店管理

## 概述

门店的选址、开办、日常运营与顾客体验。把分散的门店信息收拢成一处可查、可改、可对外呈现的中心。

## 应用

| 路径 | 说明 |
|------|------|
| `apps/qtstore` | 量潮门店中心——门店信息与顾客入口站点 (git submodule → qtstore) |

## 实验室

| 路径 | 说明 |
|------|------|
| `examples/quanttide-store-lab` | 量潮门店管理实验室——实验性与原型项目的入口 (git submodule → quanttide-store-lab) |
